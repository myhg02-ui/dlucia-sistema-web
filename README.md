# D'Lucia Muebles y Decoraciones E.I.R.L. 🛋️

Sistema web comercial y de gestión para **D'Lucia Muebles y Decoraciones E.I.R.L.** (Tiendas en Lima y Ayacucho).

## 📋 Descripción del Proyecto
- **Catálogo y Tienda Web Pública (`index.html`)**: Exhibición de muebles (salas, descanso, a medida), telas para tapicería, configurador de colores en vivo, cotizaciones y seguimiento de pedidos.
- **Panel Administrativo (`admin.html`)**: Dashboard con KPIs, control de stock mínimo con alertas de reposición, gestión de pedidos según flujo de fabricación y catálogo web.
- **Base de Datos Física (`dlucia_sistema.sql`)**: 35 tablas relacionales en MySQL 8.0 (InnoDB) con reglas de negocio, disparadores de inmutabilidad y control de inventario.

## 🚀 Despliegue en Vercel
Este proyecto está preparado para desplegarse directamente en Vercel conectando este repositorio de GitHub.
